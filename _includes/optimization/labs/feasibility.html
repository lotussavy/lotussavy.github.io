Which combinations are allowed?

Plan hours of Activity A (x) and Activity B (y). A uses two staff-hours per activity-hour; B uses one. Both use one hour of the shared time allowance.

Synthetic continuous model: every real pair in 0 ≤ x ≤ 10, 0 ≤ y ≤ 10 is a candidate. The sliders sample half-hour increments; the region between them is included. No objective or “best” point is specified.

Choose a point and change the rules

Use arrow keys on a slider. An unchecked rule is excluded; its stored limit is inactive. The 0–10 domain always applies.

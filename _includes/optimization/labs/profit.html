Objective: maximize P(n) = R(n) − C(n), where R(n) = 100n − 5n² and C(n) = 20n + 100.

Domain: n is an integer and 0 ≤ n ≤ 12. Method: exact exhaustive enumeration of 13 decisions. The unique optimum is n = 8, P = $220. Since P(n) = 220 − 5(n − 8)², no feasible decision can exceed $220.
